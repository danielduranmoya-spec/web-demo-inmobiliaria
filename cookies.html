Qué guarda esta web

Esta web no usa cookies de análisis, publicidad ni redes sociales. Solo guarda en tu navegador (localStorage) que has visto el aviso de cookies, para no volver a mostrártelo.

Servicios externos

Para funcionar, la web carga recursos de terceros. Al hacerlo, estos servicios reciben tu dirección IP:

  • Google Fonts (Google Ireland Ltd.): tipografías Cinzel y Outfit.
  • jsDelivr: librería three.js para la escena 3D.
  • GitHub Pages (GitHub Inc.): alojamiento de la web.

[PENDIENTE: en una web real, conviene alojar las tipografías y three.js en el propio servidor para no depender de terceros.]

Cómo borrar los datos

Puedes borrar lo que guarda la web desde la configuración de privacidad de tu navegador (borrar datos de sitios). Volverás a ver el aviso la próxima vez que entres.
